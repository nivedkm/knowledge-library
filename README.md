# WisdomAI

WisdomAI is a local-first personal knowledge retrieval application. It will let
you organize books and reading notes, retrieve relevant notes, and eventually
generate answers grounded only in those notes.

This repository is being built one verified milestone at a time. The current
milestone contains only the application foundation:

- A FastAPI backend with a health endpoint
- A React, Vite, and TypeScript frontend
- Tests, linting, formatting, and type-checking configuration
- No database, embeddings, retrieval, or language model yet

## How the current milestone fits together

```text
Browser
   |
   | GET /api/v1/health
   v
React frontend (localhost:5173)
   |
   v
FastAPI backend (localhost:8000)
```

The health endpoint is intentionally simple. It proves that the backend runs,
the frontend runs, and the browser can communicate with the API before we add a
database.

## Requirements

- Python 3.12 or later
- `uv` for Python dependency management
- Node.js 22.13 or later
- npm

## First-time setup

Copy the example configuration:

```bash
cp .env.example .env
```

Install backend dependencies:

```bash
cd backend
uv sync
```

Install frontend dependencies:

```bash
cd frontend
npm install
```

`uv.lock` and `package-lock.json` will be generated by these install commands.
They should be committed so every developer receives the same dependency
versions.

## Run the application

In one terminal:

```bash
cd backend
uv run uvicorn app.main:app --reload
```

In a second terminal:

```bash
cd frontend
npm run dev
```

Then open `http://localhost:5173`.

Useful backend pages:

- API health: `http://localhost:8000/api/v1/health`
- Interactive API docs: `http://localhost:8000/docs`

## Quality checks

Backend:

```bash
cd backend
uv run ruff check .
uv run ruff format --check .
uv run mypy app
uv run pytest
```

Frontend:

```bash
cd frontend
npm run lint
npm run typecheck
npm run test
npm run build
```
